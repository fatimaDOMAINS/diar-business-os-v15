# DIAR Business OS Core V12 — DubaiEstate24 × Alona pilot

V12 adds the second real-person pilot and the first domain-led investor acquisition concept.

## Purpose
Test whether the same CORE that produced a brand-first BOCOBITES growth concept can also produce a domain-led real-estate acquisition business.

## Pilot logic
Audience / investor access → DubaiEstate24.com → investor intent → structured profile → qualification → verified opportunity matching → sales conversation → CRM follow-up.

## Added
- `src/core/pilot-alona.js`
- `GET /api/core/pilots/alona`
- `public/v12-alona.html`
- five real-estate conversion lanes
- explicit investor-profile fields
- strict no-invented-inventory / no-guaranteed-return guardrails

## Validation result
This pilot intentionally treats DubaiEstate24.com as a central business asset, unlike V11 BOCOBITES where Umami365.com remained optional. This confirms that domain importance should be decided by opportunity fit, not forced across every prospect.
